
# 🥐 Тепла Булочка

**Тепла Булочка** — це багатосторінковий вебсайт булочної, створений за допомогою HTML без використання CSS та JavaScript.

## 📌 Про проєкт

Сайт представляє булочну, її продукцію, ціни та можливість оформлення замовлення через форму.

## 📄 Сторінки сайту

- `index.html` — головна сторінка.
- `catalog.html` — каталог випічки.
- `prices.html` — прайс-лист продукції.
- `about.html` — інформація про булочну.
- `gallery.html` — галерея випічки.
- `order.html` — форма замовлення.

## 🛠 Використані технології

- HTML5
- Git
- GitHub

## 🚀 Як запустити сайт

### Спосіб 1. Запуск на комп'ютері

1. Завантаж репозиторій на комп'ютер.
2. Розпакуй архів, якщо завантажив ZIP.
3. Відкрий папку проєкту.
4. Відкрий файл `index.html` у браузері.
5. Використовуй меню навігації для переходу між сторінками.

### Спосіб 2. Запуск через GitHub Pages

1. Відкрий репозиторій на GitHub.
2. Перейди в **Settings**.
3. Відкрий розділ **Pages**.
4. У блоці **Build and deployment** вибери `Deploy from a branch`.
5. У полі Branch вибери `main` і папку `/ (root)`.
6. Натисни **Save**.
7. Зачекай, поки GitHub опублікує сайт.
8. Відкрий посилання, яке з'явиться в розділі Pages.
